1. Backend setup:
   cd Backend
   pip install -r requirements.txt
   cp .env.example .env      (then fill in MONGODB_URI etc.)
   python app.py

2. Frontend setup:
   cd Frontend
   npm install
   ng serve

3. Open browser:
   http://localhost:4200

Backend:
   http://localhost:5000

Note: the backend needs a MongoDB connection (Atlas free tier or local) —
see Backend/.env.example for the required environment variables.
